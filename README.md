# Amarsia Packages Monorepo

Public monorepo for official Amarsia npm packages.

## Packages

- [`@amarsia/sdk`](packages/sdk/README.md): core TypeScript/JavaScript SDK for Amarsia APIs.
- [`@amarsia/react`](packages/react/README.md): React wrapper over `@amarsia/sdk` with simple stateful hooks.

## npm Packages

- [`@amarsia/sdk` on npm](https://www.npmjs.com/package/@amarsia/sdk)
- [`@amarsia/react` on npm](https://www.npmjs.com/package/@amarsia/react)

## Where to Start

- For framework-agnostic usage, read [`packages/sdk/README.md`](packages/sdk/README.md).
- For React/Next usage, read [`packages/react/README.md`](packages/react/README.md).

## Discoverability Notes

If you are looking for Amarsia JavaScript SDK, Amarsia TypeScript SDK, Amarsia React SDK, Amarsia conversation API SDK, or Amarsia streaming API SDK, start with the package READMEs above.
